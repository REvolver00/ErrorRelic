ERROR Relics 0.90 Beta - EVENT4 test
=======================================

Goal
----
Make BOTH event relic obtain styles produce ERROR without restoring
EVENT2's generic Obtain<T> cast softlock.

Expected:
- LostWisp Claim -> ERROR, event finishes.
- SunkenStatue GrabSword -> ERROR, event finishes.
- DollRoom relic choice -> ERROR, event finishes.
- Other event random/fixed relic obtains through the same paths -> ERROR.

How EVENT4 handles generic Obtain<T>
------------------------------------
Vanilla Obtain<T> requires the inner final Obtain to return an object
castable to T. EVENT4 obtains the ERROR into the player's inventory,
but returns the original T object only as a type-compatible return
token to the outer generic method. The original T is NOT added to the
inventory.

Regression checks
-----------------
- Neow Proof
- Merchant
- Chest
- Elite/random RelicReward
- Ancient
- Save/load after obtaining event ERROR

Build only. No PCK/assets changed.
