ERROR 0.93 presentation additions

Rotation pickup bonus
- Every ERROR pickup scans the current scene.
- Only visible TextureRect nodes with MouseFilter=Ignore are candidates.
- Card namespaces and interactive controls/hitboxes are excluded.
- Each candidate independently has a 35% chance to rotate.
- Chosen angle is independently +90 / +180 / +270 degrees.
- Repeated pickups in the same scene can rotate the same texture again.
- Original rotation/pivot is restored when SceneTree.CurrentScene changes.
- Uses System.Random local to presentation code; no gameplay RNG.

Random ERROR trigger audio
- Current supplied sts2.dll yielded 222 conservative one-shot SFX event paths.
- Ambience, obvious idle loops, directory placeholders and incomplete trailing-prefix strings were excluded.
- Every ERROR Flash chooses independently from vanilla_sfx.txt plus custom_sfx files.
- Put .ogg/.wav files into ErrorRelics/audio/custom_sfx before building.
- Custom ERROR audio hard-cuts the previous custom ERROR audio.
- Vanilla FMOD one-shots still use the game's PlayOneShot API; the exposed manager API has no StopOneShot counterpart,
  so this clean version does not pretend it can forcibly stop an already-playing vanilla one-shot.

Validation note
- Source-level integration was produced against the supplied 0.93 project and current sts2.dll data.
- This environment does not provide the project's .NET/Godot build toolchain, so final compile/runtime smoke testing
  must be done in the normal local mod build environment.
