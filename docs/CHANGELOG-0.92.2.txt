0.92.2 — 修正发布包误用旧 DLL

0.92.1 创意工坊发布包误用了 0.91.3 的 Release DLL，导致版本号显示为 0.92.1，但仅有 61 个触发条件、65 个效果，且缺少红镐子开局开关。
原因是解决方案的 Release 配置错误地映射到 Debug；构建成功后从 Release 目录取到的是旧产物。

本次修正 Release 配置并重新构建发布 DLL，包含 H001-H104、E001-E109 和“开局直接获得红镐子（保留涅奥选项）”设置。
E002、E007 继续排除随机生成，实际随机池为 104 × 107 = 11,128 种组合。
更新时请完整替换 DLL、JSON、PCK，并重启游戏。
E102 崩溃反馈尚未确认修复。
