0.91.3 Beta — 联机适配与效果说明更新

【联机】
• 支持每名玩家独立开启 ERROR Mode，并按实际持有者生成、保存和结算 ERROR 遗物。
• 调整联机商店、遗物奖励、事件和宝箱中的随机组合生成，确保双方生成结果一致。
• 多人宝箱保留原版选择、争抢和补偿流程，在分配完成后为获奖玩家生成 ERROR。
• 修正事件获取遗物的兼容处理，并在战斗开始时清理临时计数，保留跨战斗计数。

【说明与设置】
• ERROR 遗物现在显示当前组合的完整触发条件和效果，保留 H/E 编号供反馈。
• 调整中文句式、数字与关键词高亮，使说明更接近原版风格。
• 王室认证、黏糊、特兹卡塔拉的余烬等附魔，以及相关卡牌名称采用游戏原版中文译名。
• 在“模组配置 → ErrorRelics”新增“显示完整效果”开关，默认开启。
• 关闭后隐藏 ERROR 的效果说明及 H/E 编号，保留名称和图标；设置自动保存，仅影响本机显示。

【兼容与排查】
• 增加单人宝箱展示、点击、跳过及领取记录，便于排查偶发的未领取反馈。该问题尚未确认修复。
• E002（升级打出的牌）与 E007（三选一无色牌）继续暂停随机生成；原有 H/E 编号保持不变。
• 本次没有新增触发条件或效果。组合很强、很弱或没有实际作用，仍属于 ERROR 的设计范围。

【验证范围】
已在游戏 v0.111.0、BaseLib 3.4.7 下通过 47,954 次自动检查，以及本机双端联机、单人宝箱领取和显示开关测试。联机仍为预览阶段，尚未完成跨机器 Steam 联机、四人长局和断线恢复验证。

更新时请完整替换模组文件（DLL、JSON、PCK），不要只替换 DLL。需要 BaseLib 3.4.7 或更高版本。
